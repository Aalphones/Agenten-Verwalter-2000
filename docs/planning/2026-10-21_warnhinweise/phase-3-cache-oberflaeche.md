## AK der Phase

1. **Pille (1):** in „Claude“ links vom Kontext-Donut, nur wenn `session.promptCache !== null`. Warm: grün (`--color-status-completed` auf `color-mix(… 12%, transparent)`), Ring-Symbol 12 px, dessen gefüllter Anteil der Restzeit entspricht, Text „Cache <n> min“ (n = aufgerundete Minuten). Kalt: Farbe `--color-cache-cold`, Schneeflocke, „Cache kalt“. Neu: `--color-fg-muted` auf `--color-bg-hover`, Pfeil-im-Kreis, „Cache neu“. Höhe 24 px, Radius voll, Schrift 11.5 px. `title` je Zustand (Texte unten).
2. **Fenster (1):** Klick auf die Pille öffnet ein Fenster (Breite 300 px, `align="end"`, `placement="below"`) mit Überschrift je Zustand und Zeilen „Zustand“, „Im Cache“ (`formatTokens(tokens)` Token), „Haltedauer“ („1 Stunde“ bzw. „5 Minuten“, Zusatz „laut letzter Antwort“), „Letzte Antwort“ (`formatClock(anchorAt)` Uhr), „Modell“ (`modelName(model)`); darunter der Satz „Jede Antwort setzt die Uhr zurück. Ein Modellwechsel oder das Zusammenfassen des Verlaufs macht den Cache sofort kalt.“ Ein zweiter Klick oder Esc schließt.
3. **Hinweis in der Eingabeleiste (2):** oben in `composer__box` eine Zeile, wenn „Claude“, Zustand kalt und `tokens >= 100_000` und Session-Status nicht `new`. Text bei Ablauf: „**<Pause> Pause, der Cache ist abgelaufen.** Deine nächste Nachricht schreibt rund <formatThousands(tokens)> Token neu in den Cache, statt sie günstig daraus zu lesen.“ Bei anderem Modell: „**Der Cache gilt für <Cache-Modell>.** Mit <Session-Modell> schreibt deine nächste Nachricht rund <x> Token neu in den Cache.“ Rechts Knopf „In neuer Session weiter“ (Titel: „Legt im Vorhaben eine neue Session an und öffnet sie — sie startet mit kleinem Verlauf.“). Das Schneeflocken-Symbol trägt als Erklärung den `title` „Claude hält den Verlauf nach jeder Antwort eine Zeit lang bereit (Prompt-Cache). Danach liest er ihn neu ein — das zählt deutlich stärker aufs Kontingent als das Lesen aus dem Cache.“
4. **Modell-Menü (3):** solange der Cache warm ist und das Menü für Claude-Modelle offen ist, steht über der Fußzeile ein Kasten: „**Der Cache gilt nur für <Cache-Modell>** und hält noch <n> min. Mit einem anderen Modell schreibt die nächste Nachricht rund <x> Token neu.“
5. In „Claude Code + LM Studio“, „Autark“ und „Codex“: keine Pille, kein Hinweis, kein Kasten.

- [ ] `src/features/promptcache/promptCacheState.ts` (reine Funktionen):
  - `export const COLD_HINT_MIN_TOKENS = 100_000;` mit Kommentar (Grundlast ~64 000 Token, darunter spart eine neue Session nichts; ADR 033).
  - `export type PromptCacheState = { kind: 'unknown' } | { kind: 'warm'; msLeft: number; minutesLeft: number; fractionLeft: number } | { kind: 'cold'; reason: 'expired'; idleMs: number; expiredAt: number } | { kind: 'cold'; reason: 'model' } | { kind: 'fresh' };`
  - `export function promptCacheState(cache: PromptCache | null, model: ModelId, now: number): PromptCacheState` — Reihenfolge: `null` → unknown; `compactedAt !== null` → fresh; `cache.model !== model` → cold/model; `msLeft = cache.anchorAt + cache.ttlMs - now`; `> 0` → warm (`minutesLeft = Math.ceil(msLeft / 60_000)`, `fractionLeft = msLeft / cache.ttlMs`); sonst cold/expired (`idleMs = now - cache.anchorAt`, `expiredAt = cache.anchorAt + cache.ttlMs`).
  - `export function formatIdle(ms: number): string` — unter 60 min „<m> min“; unter 24 h „<h> h“ bzw. „<h> h <m> min“; sonst „1 Tag“/„<d> Tage“ plus „ <h> h“, wenn h > 0.
  - `export function cacheTtlLabel(ttlMs: number): string` — 3 600 000 → „1 Stunde“, 300 000 → „5 Minuten“, sonst „<n> Minuten“.
