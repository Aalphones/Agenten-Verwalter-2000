# Entwurf „Skins“

| Datei | Zeigt | Phasen |
|---|---|---|
| `entwurf-skins.html` | Einstellungsseite „Skins“ (links) mit Abschnitten Figuren, Stil, Pakete, Agent, Figuren-Editor mit eigenen Fächern, Stil-Editor; Vorschau des Verwalters (rechts) mit Statuszeile, Taktung, Denken, Feier-Moment, Stilpaket; Regeln, Werkzeugliste, ZIP-Format | 1, 3, 4, 5, 6, 7 |

**Ansehen:** Datei im Browser öffnen. Direkt in einem Zustand: `#beispiel` (Pokémon + Stilpaket aktiv), `#editor` (Figuren-Editor, Fach GitHub offen), `#stil` (Stil-Editor). Ohne Anker: Werkszustand (alles aus).

**Werte:** Farben, Radien und Abstände aus `src/styles/theme.css` (dunkel/hell). Die Bewegungen (CSS `@keyframes`, SVG in `stageHtml`) sind die Vorlage für Phase 3.

**Platzhalter:** Die Beispiel-Sprites liegen absichtlich nicht im Repository (Rechte Dritter). Im Repository zeigt der Entwurf deshalb leere Bilder; die vollständige Fassung mit Bildern liegt im Artefakte-Ordner des Vorhabens, die Bilder stammen von `img.pokemondb.net` (Schwarz/Weiß-Sprites). Hintergrundbilder: Unsplash (per Adresse eingebunden). Paketnamen, Sessionnamen und Werkzeugaufrufe sind Beispielwerte.
