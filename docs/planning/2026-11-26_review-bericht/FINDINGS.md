- [x] → Phase 3: `db::report::load_phases` liefert die Zeilen von `report_phases`. Eine Zeile kann bis auf die IDs leer sein (nichts zu ordnen). Die ID-Prüfung lässt einen Stopp ohne IDs durch; beim Zusammensetzen damit umgehen, ohne die Indizes von `way[].stop` zu verschieben. `tidy_json` liest sich als `report::tidy::TidyAnswer` (`StopKind::as_str`).
