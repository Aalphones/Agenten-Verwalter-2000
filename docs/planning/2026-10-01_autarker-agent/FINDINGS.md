# Findings — Autarker Agent

Erkenntnisse während der Umsetzung, je eine Zeile, getaggt mit der Phase, die sie aufgreift: `- [ ] → Phase N: <Erkenntnis>`. Erledigt → `[x]`.

- [ ] → Phase 2: `interrupt` meldet `result_aborted` sofort und hängt `[Request interrupted by user]` (Rolle `user`) **sofort** ans Transkript (`Session::interrupt`); der Arbeits-Thread läuft weiter, bis er den Abbruch merkt, und erst danach beginnt der nächste Turn (`ActiveTurn.is_aborted`). Schreibt in Phase 2 der Arbeits-Thread Werkzeug-Ergebnisse ins Transkript, käme der Marker vor die `tool`-Nachrichten und das Format bräche (assistant mit `tool_calls` ohne direkt folgende Ergebnisse). Lösung dort: alle Transkript-Schreibzugriffe eines Turns an einer Stelle — z. B. der Thread gibt seine Nachrichten zurück und die Hauptschleife hängt sie samt Marker in der richtigen Reihenfolge an, oder der Marker kommt erst, wenn der Thread zurück ist.
- [ ] → Phase 2: `request_messages` legt aufeinanderfolgende `user`-Nachrichten zu einer zusammen (`content::merge_user`), weil manche Chat-Vorlagen zwei in Folge ablehnen; `tool`-Nachrichten sind davon nicht berührt.
- [ ] → Phase 3: Die Session führt noch keinen Modus — `set_permission_mode` prüft den Wert nur. Feld `mode` in `Session` ergänzen (Start aus `args.mode`, `args::mode_from_cli` für die Steueranfrage). Eingehende `control_response`-Zeilen werden bisher still überlesen (`handle_line`).
- [ ] → Phase 5: TL;DR in „Autark“: `start_session_tldr`/`start_project_tldr` rufen `find_claude()` **vor** `ask_haiku` — ohne installierte Claude-Kommandozeile kommt „Claude nicht gefunden“ statt des Satzes aus `ask_haiku`. Beim Bau des Druckmodus die Programmwahl wie in `start_process` vorziehen.
- [ ] → Phase 7: Eine Anfrage mit unbekanntem Modellnamen beantwortete LM Studio erst nach 132 s, dann mit dem geladenen Modell. Hypothese (nicht belegt): sie wartete hinter einer vorher abgebrochenen Anfrage — ob LM Studio nach dem Schließen der Verbindung aufhört zu rechnen, ist offen. Wichtig für die Zeitgrenze der Modellanfrage.
- [ ] → Phase 9: AK 2 (keine `claude.exe` in „Autark“): Die Einstellungsseite liest das Claude-Konto unabhängig von der Betriebsart (`AccountRow` → `account_load` → `claude auth status --json`). In „Autark“ startet das eine `claude.exe`, sobald die Einstellungen offen sind.
