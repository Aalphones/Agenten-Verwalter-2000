## Abnahmekriterien der Phase

1. **Dialog-Baustein:** rendert per Portal in `document.body`; Abdunklung über das ganze Fenster (`--color-scrim`, Ebene `--z-modal`), Feld mittig. Esc, Klick auf die Abdunklung (nicht auf das Feld) und `onClose` schließen; Esc pausiert die Session nicht. Beim Öffnen hat das erste bedienbare Element den Fokus, Tab und Umschalt+Tab bleiben im Feld, nach dem Schließen steht der Fokus wieder dort, wo er vorher war.
2. **Schalter-Baustein:** echter `<button role="switch" aria-checked>`; 34 × 20 px, Knopf 16 px; an: `--color-toggle-on`, Knopf rechts; aus: `--color-toggle-off`, Knopf links; Knopf `--color-fg-on-toggle`; Übergang mit `--duration-base`/`--ease-out`; gesperrt halb durchsichtig.
3. **Dialog „MCP-Server“** nach `canvas/Main.dc.html`: 640 px breit, höchstens 780 px hoch (und nie höher als das Fenster abzüglich 2 × 32 px); Kopf mit „MCP-Server“ (15 px, 600) und zweiter Zeile „Session #N Name“, X-Knopf 28 × 28 px; Filterfeld 30 px hoch mit Lupe; nur die Liste scrollt; Fußzeile mit Zählung, dem Satz zum Ausschalten und „Schließen“.
4. **Servergruppen** nach Herkunft in der Reihenfolge Benutzer, Projekt, Lokal, claude.ai, Organisation, Kommandozeile, danach Unbekanntes; Titel „<Herkunft> (<Anzahl>)“. Der Filter wirkt auf den Namen, ohne Groß-/Kleinschreibung; ohne Treffer „Kein Server passt zu „<Filter>“.“.
5. **Serverzeile:** Karte mit 1 px Rand (`--color-border-subtle`, aufgeklappt `--color-border` und Hintergrund `--color-bg-hover`), Radius 8 px. Pfeil (dreht sich aufgeklappt um 90°), Statuspunkt 8 px, Name in Monospace, darunter Verbindung und bei „Verbunden“ die Werkzeuganzahl; rechts Statuswort in Statusfarbe, Knopf „Neu verbinden“ 30 × 30 px mit Kreispfeil, Schalter. Statusfarben: Verbunden `--color-status-completed`, Verbindet `--color-status-running`, Fehlgeschlagen `--color-status-error`, Anmeldung nötig `--color-status-waiting`, Aus und Unbekannt `--color-fg-muted`. Ausgeschaltet: Name und Unterzeile gedämpft.
6. **Aufgeklappt:** Herkunft und Verbindung als zwei Zeilen; bei „Verbunden“ alle Werkzeugnamen als Monospace-Kärtchen, höchstens 148 px hoch, danach scrollbar; bei „Fehlgeschlagen“ ein Kasten in `--color-status-error` auf `--color-status-error-subtle` mit „Verbindung fehlgeschlagen“ und dem Fehlertext; bei „Aus“, „Verbindet“, „Anmeldung nötig“ je ein Satz (Texte unten).
7. **Aktionen:** „Neu verbinden“ und Schalter rufen die Commands; solange der Server in `busy` steht, dreht sich das Kreispfeil-Symbol (bei `prefers-reduced-motion: reduce` nicht) und beide Bedienelemente sind gesperrt. „Neu verbinden“ ist bei „Aus“ gesperrt. Ein Aktionsfehler (aus `SessionMcp.error` oder ein abgelehnter Command) steht als Zeile in Fehlerfarbe unter dem Filter.
8. **Erklärung an jedem Bedienelement:** Tooltip am Schalter „Ausschalten: der Agent sieht die Werkzeuge dieses Servers nicht mehr. Gilt für alle Sessions dieses Vorhabens, auch nach einem Neustart.“; am Knopf „Verbindung zu diesem Server neu aufbauen“; `aria-label` beider mit dem Servernamen.
9. **Ohne Liste** stehen die Texte aus „Texte“ unten statt Filter und Liste; Fußzeile dann nur mit „Schließen“.
10. Solange der Dialog offen ist und ein Server „Verbindet …“ zeigt oder eine Aktion läuft, fragt er alle 2 s nach; geschlossen fragt er nicht.
11. `pnpm check` grün.

## Texte (`src/features/mcp/mcpTexts.ts`, wörtlich)

| Schlüssel | Text |
|---|---|
| Status `connected` / `pending` / `failed` / `needsAuth` / `disabled` / `unknown` | Verbunden / Verbindet … / Fehlgeschlagen / Anmeldung nötig / Aus / Unbekannt |
| Gruppe je `scope`: `user` / `project` / `local` / `claudeai` / `enterprise` / `dynamic` / leer / sonst | Benutzer / Projekt / Lokal / claude.ai / Organisation / Kommandozeile / Sonstige / der `scope`-Wert selbst |
| Herkunft (Details) je `scope`, gleiche Reihenfolge | Benutzer-Konfiguration / Projekt-Konfiguration (.mcp.json) / Lokale Konfiguration / claude.ai-Connector / Organisation / Beim Start übergeben / unbekannt / der `scope`-Wert selbst |
| Werkzeuganzahl | „1 Werkzeug“ / „N Werkzeuge“; Titel aufgeklappt „Werkzeuge (N)“; ohne Werkzeuge „Keine Werkzeuge gemeldet.“ |
| Details „Aus“ | Ausgeschaltet – der Agent sieht die Werkzeuge dieses Servers nicht. |
| Details „Verbindet“ | Verbindet … |
| Details „Anmeldung nötig“ | Der Server braucht eine Anmeldung, die der Verwalter nicht anbietet. Melde dich einmal in Claude Code an (Befehl /mcp im Terminal oder in der VS-Code-Erweiterung) und verbinde ihn dann hier neu. |
| Fehlerkasten ohne Text | Die Kommandozeile nennt keinen Grund. |
| Aktionsfehler je `action` `reconnect` / `enable` / `disable` | Neu verbinden von „{server}“ fehlgeschlagen: {text} / Einschalten von „{server}“ fehlgeschlagen: {text} / Ausschalten von „{server}“ fehlgeschlagen: {text} |
| Zählung (Fußzeile) | „{verbunden} von {gesamt} verbunden“, dahinter nur wenn > 0: „ · {n} fehlgeschlagen“, „ · {n} Anmeldung nötig“, „ · {n} aus“ |
| Satz Fußzeile | Ausgeschaltete Server bleiben für alle Sessions dieses Vorhabens aus. |
| Ohne Liste: lädt (`mcp === null` oder `servers === null` bei laufendem Agenten) | MCP-Server werden geladen … |
| Ohne Liste: Session „Neu“ | Die MCP-Server starten mit dem Agenten. Schick die erste Nachricht, dann erscheinen sie hier. |
| Ohne Liste: Agent läuft nicht | Der Agent dieser Session ruht gerade, und mit ihm seine MCP-Server. Schick eine Nachricht, dann erscheinen sie hier wieder. |
| Liste leer | Keine MCP-Server eingerichtet. Einrichten geht in der Claude-Kommandozeile mit „claude mcp add“ oder als Connector auf claude.ai. |
