# FINDINGS — Codex als Betriebsart

Erkenntnisse während der Umsetzung, getaggt mit der Phase, die sie betreffen:

- [x] → Phase 2: `thread/start` nimmt `sandbox` als `SandboxMode`-Text (`read-only`, `workspace-write`, `danger-full-access`), nicht als Objekt; `writableRoots`/`networkAccess` gehen nur über `sandboxPolicy` (Objekt `SandboxPolicy`) in `turn/start`. Phase 1 setzt in `thread/start` nur `approvalPolicy: "on-request"` und Planen → `read-only`, sonst `workspace-write`; `turn/start` schickt `approvalPolicy: "on-request"` fest mit — beides in `codex/session.rs` durch die Modus-Zuordnung ersetzen.
- [x] → Phase 2: Antwort auf `item/commandExecution/requestApproval` und `item/fileChange/requestApproval` ist `{"decision": "accept" | "acceptForSession" | "decline" | "cancel"}` (bei Befehlen zusätzlich Objekt-Varianten); `item/tool/requestUserInput` will `{"answers": {<frage-id>: {"answers": [..]}}}`. Phase 1 lehnt beide Freigaben mit `decline` ab und beantwortet alle anderen Server-Anfragen mit einem JSON-RPC-Fehler (`decline_request`).
- [x] → Phase 2: Der MCP-Dialog und die Zeile „mcp“ im `/`-Menü sind in „Codex“ noch sichtbar (`commandMenuRows.ts`); laut README ausblenden. `mcp_status` beantwortet der Übersetzer schon mit `error`.
- [x] → Phase 2: Benachrichtigungen, die Codex schon bei einem reinen Text-Turn schickt und die der Übersetzer noch meldet (einmal je Name auf stderr): `mcpServer/startupStatus/updated`, `thread/status/changed`, `turn/started`, `item/started`, `item/agentMessage/delta`, `thread/tokenUsage/updated`. Bekannte, bewusst ignorierte Namen in die Liste der stillen aufnehmen.
- [ ] → Phase 6: Skills aus einem Repository oder ohne Spiegel in `~/.codex/skills` gehen als Text (Codex verwirft `skill`-Einträge außerhalb seines Katalogs ohne Meldung); die Hilfe zu „Codex“ nennt, dass Skills nach `~/.codex/skills` gespiegelt sein müssen, damit Codex ihre Nebendateien selbst liest. Dazu `$ARGUMENTS`-Ersetzung bei Befehlen unverändert wie Autark.
- [x] → Phase 3: Das Scratchpad steht in der `init`-Zeile; die Vorgabe an Codex (`--append-system-prompt` mit Scratchpad und Artefakten) wertet der Übersetzer noch nicht aus. `developerInstructions` in `thread/start`/`thread/resume` ist der Platz dafür.

- [x] → Phase 5: `SessionHeader` zeigt das Kontingent nur bei `claude`; `commands/usage.rs` lädt es nur in „Claude“.
