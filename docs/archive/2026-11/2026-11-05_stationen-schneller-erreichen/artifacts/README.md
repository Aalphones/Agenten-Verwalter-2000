# Entwürfe

| Datei | Zeigt | Phase |
|---|---|---|
| `stationen-schneller-erreichen.html` | Sieben Vorschläge mit Entwurf; gewählt sind A (Stationen in der Sidebar), C (Rückweg-Leiste), F (Sprung per Kürzel), G (Zeitleiste öffnet bei der ersten aktiven Phase) | A → 1, C → 2, G → 3, F → 4 |

Ansehen: die Datei im Browser öffnen, sie lädt nichts nach. Die Entwürfe sind HTML-Nachbauten der dunklen App-Oberfläche mit fest eingetragenen Farben aus `src/styles/theme.css`, keine echten Komponenten. Platzhalter: Namen, Zeiten und Zahlen der Beispiel-Umsetzungen; das Kürzel heißt im Entwurf „Strg+J“, in der App „Ctrl J“ (Schreibweise wie „Ctrl N“). Verbindlich sind die Phasen-Dateien; wo sie vom Entwurf abweichen, gelten sie.
