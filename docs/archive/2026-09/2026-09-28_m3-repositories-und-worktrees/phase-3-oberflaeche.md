## Abnahmekriterien der Phase

1. `pnpm check` grün.
2. „Neue Session“ zeigt drei Schritte: „1 Was soll erledigt werden?“, „2 Repositories“, „3 Agent“. Schritt 2 nach Entwurf: Liste im Kasten (Rahmen 1 px `border-subtle`, Radius 8 px, Zeilen durch 1 px `border-subtle` getrennt), je Zeile Häkchen 14 px in Akzentfarbe, Name 120 px breit (Gewicht 500), Pfad `font-mono` 12 px `fg-muted` mit Auslassungspunkten, rechts Skill-Zahl 12 px `fg-muted` („2 Skills“, „1 Skill“, „keine Skills“); Zeilen-Innenabstand 8 px 12 px, Abstand 10 px. Darunter Knopf „Repository hinzufügen …“ (Höhe 28 px, Rahmen 1 px `border`, Radius 6 px, 12 px, Plus-Symbol 12 px) und daneben ⓘ (13 px) mit dem Satz „Jedes Repository bekommt einen eigenen Worktree. Seine Skills stehen in der Session zur Verfügung.“
3. „Repository hinzufügen …“ öffnet den Ordner-Dialog von Windows (Titel „Repository wählen“). Ein gewählter Ordner in einem Repository erscheint als Zeile und ist sofort angehakt; ein Ordner ohne Repository zeigt unter der Liste „Der Ordner ist kein Git-Repository: <Pfad>“ in Fehlerfarbe; Abbrechen im Dialog ändert nichts.
4. Ein fehlendes Repository (`isMissing`) zeigt statt der Skill-Zahl „nicht gefunden“ in `status-error`, das Häkchen ist gesperrt, rechts daneben ein Textknopf „Entfernen“; nach dem Klick ist die Zeile weg.
5. Ohne bekannte Repositories steht statt des Kastens der Satz „Noch keine Repositories. Ohne Repository arbeitet der Agent in einem leeren Ordner.“ (12 px `fg-muted`).
6. Die Fußzeile nennt „n Repositories · Modell · Modus“ (1 → „1 Repository“, 0 → „Kein Repository“); während des Starts mit mindestens einem Repository „Worktrees werden angelegt …“, und „Session starten“ ist gesperrt.
7. Fehler beim Start stehen in der bestehenden Fehlerzeile: `repositoryMissing` → „Repository nicht gefunden: <Pfad>. Entferne es aus der Liste oder stelle den Ordner wieder her.“; `git` → „Worktree konnte nicht angelegt werden — <Text>“; `gitNotFound` → „Git nicht gefunden. Installiere Git für Windows und starte die App neu.“
8. Die Sidebar-Meta-Zeile einer laufenden oder startenden Session lautet „n Repositories · Modell“ bzw. „1 Repository · Modell“, bei 0 Repositories nur „Modell“; pausiert davor „pausiert · “.
9. Der Leerzustand nennt den Text aus dem Entwurf („Eine Session ist eine Aufgabe für einen Agenten, über ein oder mehrere Repositories. Jedes bekommt einen eigenen Worktree, damit parallele Agenten sich nicht in die Quere kommen.“).
